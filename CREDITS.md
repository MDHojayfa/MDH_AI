## What is original here

| Layer | What it does |
|---|---|
| `src/content/injected.js` | a MAIN-world tap on `fetch`, XHR and WebSocket that copies a reply without changing what the page receives |
| `src/core/interceptor.js` | turns those copies into one stream shape — SSE, byte-framed, body-mode |
| `src/core/parser.js` | finds the call envelope in a reply, repairs almost-JSON, explains failures to the model |
| `src/core/agent.js` | the send/read/govern/refuse/deliver loop and its state machine |
| `src/platforms/*.js` | the eight adapters: host patterns, read mode, composer, send button |
| `src/core/policy.js` + `host/tools/linux.mjs` | two independent guards, one lexical and one that resolves symlinks |
| `host/*.mjs` | a native-messaging host with an MCP client, an audit chain and thirteen builtin tools |

## How it was built

By reading public documentation, the observable behaviour of the eight web apps, and the public
specifications of the protocols involved. No source file from another project was copied into this
repository, and no code was generated by transplanting one; that is why the licence is plain MIT.

The model itself is not bundled and is not the author's: it is whichever chat the user is already signed
into. MCP servers are started by the host as child processes and remain under their own licences and their
own authors; none of their code lives here.

Icons, diagrams and the interface are original to this project.
