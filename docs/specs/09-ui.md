# 09 · UI — popup, approval card, in-page notices

The UI has exactly one job: **make the approval decision fast and honest.** Everything else is a status
indicator. There is no dashboard, no chat window of our own (the site is the chat), no settings wizard.

Constraints: vanilla DOM, Shadow DOM, no framework, no remote fonts, no images we do not ship, works in
both Chromium and Firefox, ≤ 30 KB total.

---

## 1. Popup (360 px wide, ~420 px tall)

```
┌──────────────────────────────────────────────┐
│  MDH_AI                              ● ready │   ← 24 px, dot: green/amber/red
│                                              │
│  ChatGPT · chatgpt.com                       │
│  Native host: connected                      │
│  Tools: 13 builtin · 3 MCP servers (41)      │
│                                              │
│  ┌────────────────────────────────────────┐  │
│  │ Task (optional)                        │  │
│  │ find every PNG over 5 MB and list them │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  [ Start on this tab ]   [ Stop ]            │
│                                              │
│  ── this session ──────────────────────────  │
│  turn 7 · 2 calls · 1 denied · 03:12         │
│                                              │
│  ▸ Last 5 calls                              │
│    ✓ list_dir  ~/Pictures        0.1 s       │
│    ✓ run_command  du -sh *       2.4 s       │
│    ✗ write_file  /etc/hosts      denied      │
│                                              │
│  ⚙ Policy    ☰ Audit    ? Help               │
└──────────────────────────────────────────────┘
```

States of the status dot:

| dot | text | meaning |
|---|---|---|
| ● green | `ready` | host connected, platform recognised, no task running |
| ● amber | `running · turn 7` | loop active |
| ● amber pulsing | `waiting for approval` | the model asked, the card is up |
| ● red | `host offline` | `connectNative` failed — the number one support issue |
| ● red | `unsupported page` | hostname not in the 8 |

The Task box is **optional**: leaving it empty starts a session where the model waits for the user to
type. That is the common case — most users just want tools in the tab they are already chatting in.

## 2. Approval card (in-page, Shadow DOM)

```
┌────────────────────────────────────────────────┐
│  ⚠ MDH wants to write a file                   │
│                                                │
│  write_file                                    │
│  ┌──────────────────────────────────────────┐  │
│  │ ~/projects/app/config.json               │  │
│  │                                          │  │
│  │ { "port": 3000 }        (12 lines)       │  │
│  └──────────────────────────────────────────┘  │
│                                                │
│  ☐ Remember for this tab                       │
│                                                │
│        Deny          Allow once          Allow │
└────────────────────────────────────────────────┘
```

Rules:
- **Anchor**: bottom-centre, 16 px above the composer. Never over it, never over the send button.
- **Argument preview** is truncated to 6 lines with a `+41 more` line. `run_command` shows the command
  in monospace, no elision — a truncated command is a lie.
- **Never pre-focused on Allow.** Focus starts on the card (not a button); `Enter` = Allow once,
  `Esc` = Deny, `Tab` cycles. A model-generated `alert()`-style dialog that steals a keystroke is a
  security bug.
- **`Remember for this tab`** writes an `always` rule for that exact tool *signature* (name + the first
  path/command token), never a wildcard by default. The advanced wildcard lives in Policy.
- **Timeout** 120 s → deny, card fades, `[MDH_RESULT status="denied"]` is sent.
- **Renders the request, not the model's claim.** Everything shown comes from the parsed call, never
  from prose in the reply.

## 3. In-page notices

| kind | where | lifetime | text |
|---|---|---|---|
| `inject` | top-right toast | 6 s | `Tools attached to this chat.` |
| `rate-limit` | bottom-centre, above card | until resolved | `Rate limited. Resuming in 40 s · attempt 2/3` + `Stop` |
| `parse-retry` | toast | 5 s | `Re-asking the model to fix its call format…` |
| `reload` | toast, red | 8 s | `Page reloaded — the running call was lost.` |
| `denied-loop` | card | modal | `The model asked again for something you denied. Stop it?` |

Notices are `aria-live="polite"`; the approval card is `role="dialog" aria-modal="false"` (it must not
trap focus — the user may need to scroll the chat).

## 4. Visual language

- One accent colour, one radius (10 px), one shadow. Dark by default, `prefers-color-scheme` respected.
- 14 px body, 13 px monospace for commands and paths, 12 px metadata.
- No brand colours from any of the 8 platforms. We must look like *our* thing on top of theirs, not a
  cosplay of it.
- Icons: inline SVG, 3 files (`shield`, `terminal`, `warning`). Static — `web-ext lint` warns about
  SVG in `background` icons, so we keep them in the popup only.

## 5. Copy rules

- Never say "AI". Say "the model" or "it".
- Never say "MCP" in the popup. The user does not care; the settings page says it once.
- Errors say what happened and what to do: `Native host offline — run ./install.sh again.` not
  `Error: connectNative failed (code 1)`.
- No exclamation marks. No emoji in chrome UI. No "Oops".

## 6. Accessibility & i18n

- All interactive elements reachable by keyboard; visible focus ring (2 px, offset 2).
- Contrast ≥ 4.5:1 in both schemes; the amber status uses text + dot, never colour alone.
- Every string goes through `t(key)` with an English table in `src/popup/i18n.en.js`. v1 ships English
  only, but the indirection exists so Bangla is a data file, not a refactor (v1.1).
- Numbers and durations are locale-formatted; timestamps are relative (`3 s`, `12 min`).

## 7. What the UI must never do

- Show a "chat" of its own. Two scrollbacks of the same conversation is confusing and doubles the DOM.
- Auto-approve after an idle timeout. Silence is not consent.
- Hide a running call behind a collapsed section — the notice stays until it resolves.
- Take more than 100 ms to render the approval card after the parse. Latency here reads as "it broke",
  and a confused user clicks Allow.

## 8. Revision after the second survey (`research/07-UI-INTEL.md`)

Four additions, all evidence-backed.

### 8.1 Countdown bar — the "clock"

A rate-limit wait is a state, not an event; it must be visible for its whole duration.

```
┌──────────────────────────────────────────────┐
│ ⏱  Rate limited by DeepSeek    resuming  00:34│
│    attempt 2 of 3 · 5 messages this minute    │
│                              [Pause]  [Stop]  │
└──────────────────────────────────────────────┘
```

- `mm:ss` from **wall clock** (`resumeAt - Date.now()`), never from counting ticks — background tabs
  throttle timers and the number would drift.
- At zero it becomes `Resuming…`; it disappears only when the send is *accepted*, so a failed resume
  shows the next countdown instead of a lie.
- After the final stop: `Paused — press Resume`, with one button.
- Tone is neutral-amber, not red: a rate limit is normal operation on a free tier.

### 8.2 Pipeline strip (popup)

Replaces the single status dot when anything is wrong:

```
page found        ✓   0 ms
host connected    ✓   14 ms
tools loaded      ✓   4 ms · 41 tools
idle              ·   —
```

Four stages, never more. A user's bug report becomes a stage name instead of "it's stuck".

### 8.3 Timestamps (off by default)

After each tool result in the transcript, a quiet chip with the machine's local time:

```css
.mdh-when { margin-left: .5em; font-size: .85em; font-variant-numeric: tabular-nums; opacity: .45; }
```

Toggle lives in the popup (`🕐 Timestamps`). Off by default because almost nobody reads it — until they
need to know what happened between two calls.

### 8.4 Stall card

- **clock icon** — a call block that was already incomplete when the page loaded (nothing we did).
- **warning icon** — a reply that stalled while we were watching (>10 min without new characters).

```
⚠ No progress for 10 minutes
   The model may still be thinking, or the page lost the stream.
   [Keep waiting]                    [Stop]
```

Silence is never rendered as a provider limit, and never as a model decision (`research/08` L33).
