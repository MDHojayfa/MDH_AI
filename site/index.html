Two minutes, one script

The installer registers the native host, builds both extension artifacts, and finishes by actually talking to the host — a real ping, not an assumption.

$ git clone https://github.com/MDHojayfa/MDH_AI && cd MDH_AI
$ ./install.sh
  ✔ node 22.22.3 — newer than Sputnik, which is the bar
  ✔ chromium id oegdcjbfbcjpogbplakppjddiojflepk
  ✔ both artifacts built
  ✔ host answered: dev.mdhojayfa.mdh v1.0.0 · audit ok

then chrome://extensions → Developer mode → Load unpacked → dist/chrome

What it can actually do

Thirteen builtin tools on this machine, plus every MCP server you already run.

Files

List, read with line numbers, write atomically, edit one exact match, search with ripgrep, inspect metadata. Outside the allowlist, nothing opens.

Shell

One command or up to twenty in a single shell, with a working directory, a timeout and the exit code of the first failure. Batched commands keep their cd.

Desktop

Launch GUI applications in your session, and hand over to an MCP server when the job needs a real browser, a database or a screen reader.

Approval

Every write and every command stops at a card that shows the parsed request, not the model's prose. Deny, allow once, or allow for the session.

Guards

Two independent path checks — a lexical one in the extension, a canonical one in the host that resolves symlinks. ~/.ssh and keyrings are denied by name.

Recovery

Sends are paced. A refusal walks a ladder instead of retrying into a ban: reload, wait, fresh chat, then pause and offer Resume.

Handing a model a shell is a serious thing

So the product is built like it: no listening port, two path guards, a card before anything happens, and a log you can verify.

  • Native messaging — the browser spawns the host, nothing is reachable from a web page.
  • The approval card renders the parsed request, never the model's description of it.
  • Commands ask even when a policy says allow, because a command can do anything.
  • Audit lines are hash-chained; editing one breaks the chain.
  • No telemetry, no remote config, no code fetched at runtime.

Questions people actually ask

The long answers are in the repository's FAQ.

Do I need an API key?

No. There is no key, no provider setting and no model picker anywhere in the product. The model is the chat you are already signed into.

Which AI platforms work?

Eight in v1: ChatGPT, Claude, Gemini, DeepSeek, Kimi, Qwen, GLM and Grok. Each has its own adapter, so a redesign on one site costs one file.

Which browsers?

Chrome 116+, Brave, and Firefox 140+. Firefox is first-class — the design avoids the debugger API Firefox does not have, which is why most tools in this space cannot run there at all.

Windows or macOS?

Not in v1. The host is the only OS-specific layer, so a port is real work rather than a flag.

Is it safe to give an AI a shell?

Safer than most, and not risk-free. Approval on every write and command, a card that shows the real request, two path guards, and an audit chain. Prompt injection is not solved, so read the card.

What happens when I hit a rate limit?

The loop stops instead of hammering. It reloads, waits longer, opens a fresh chat, then pauses and offers Resume. Your account matters more than the task.

Can I start a task without the popup?

Yes. A small pill sits above the chat box on every supported site: click to start, click to pause, click to continue, drag it if it is in the way. It remembers the last task, so restarting after a refresh is one click.

Where can I see what it actually did?

mdh-log writes one self-contained HTML file with every call, its time, its status and its audit hash — no script in the page, nothing fetched. mdh-log --serve gives a live view on 127.0.0.1 with a token that dies with the process.

Something broke. Who fixes it?

You report it, and the same person reads it. The popup opens with a line about exactly this and two buttons that pre-fill the form with the stage, platform and browser — never with your paths. If the loop dies, the card in the page carries the form next to the real error.

It asked me to share it. Why?

Once per profile, and then it stays a button. The link carries no tracking parameter, and the two destinations that cannot accept a pre-filled post — Instagram and TikTok — copy the link and say so instead of pretending.

Why does it talk about Pluto?

Because “waiting” for ninety seconds reads as broken, and “setting up the laser weapon on Pluto” reads as alive. Everything funny is tagged, and --no-fun removes it.
